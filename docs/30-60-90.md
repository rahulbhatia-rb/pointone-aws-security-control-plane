# 30 / 60 / 90 Day Security Roadmap

## First 30 days
- map AWS accounts, trust relationships, IAM admins, network exposure, KMS ownership
- enumerate public and cross-account attack paths
- baseline CloudTrail/log retention and incident evidence
- inventory Lambda/SQS/RDS concurrency and failure modes
- identify highest-risk privilege escalation paths

## By 60 days
- organization-level SCP invariants
- permission-boundary baseline
- centralized immutable logging
- workload identity / secret-management standard
- infrastructure threat-model review template
- incident-response exercises
- private connectivity baseline

## By 90 days
- automated IAM privilege-escalation checks
- blast-radius scorecard per service
- multi-account security reference architecture
- security deployment gate in CI
- automated response for selected credential incidents
- resilience/load tests for Lambda/SQS/RDS
- cost/isolation decision framework
